# obj-3d-models

开源 OBJ 格式 3D 模型仓库

Open-source repository for 3D models in Wavefront OBJ format.

## 关于 / About

本仓库用于收集、分享和支持 OBJ (.obj) 格式的 3D 模型文件。OBJ 是一种广泛使用的 3D 模型格式，易于导入到各种 3D 软件和引擎中。

This repository is dedicated to collecting, sharing, and supporting 3D models in the Wavefront OBJ format. OBJ is a widely used 3D model format that is easy to import into various 3D software and engines.

## 如何贡献 / How to Contribute

1. Fork 本仓库
2. 将你的 .obj 文件（及相关 .mtl 材质文件）添加到 `models/` 目录
3. 提交 Pull Request

欢迎任何高质量的 OBJ 模型贡献！

## 目录结构 / Directory Structure

- `models/` : 存放 3D 模型文件
- `LICENSE` : MIT 开源许可
